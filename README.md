# Email Ban Checker

Демонстрационная форма, которая проверяет email по локальному списку заблокированных адресов.

## Возможности

- Проверка формата email и обработка пустого поля.
- Поиск по списку без учёта регистра и пробелов по краям.
- Отправка формы кнопкой «Проверить» или клавишей Enter.
- Вывод результата на странице и сброс сообщения при изменении адреса.

## Используемые технологии

HTML5, CSS3 и JavaScript.

## Запуск

Откройте [index.html](index.html) в браузере. Для запуска достаточно файлов проекта.

## Примеры проверки

| Email | Результат |
| --- | --- |
| `spam@example.com` | Заблокирован |
| `user@example.com` | В списке отсутствует |

## Структура проекта

- [index.html](index.html) – разметка формы.
- [style.css](style.css) – оформление и адаптивная вёрстка.
- [script.js](script.js) – тестовый список и логика проверки.
- [REPORT.md](REPORT.md) – отчёт для анкеты.
- [screenshots/demo.png](screenshots/demo.png) – снимок проверки в браузере.

## Ограничения

Проверка выполняется в браузере по тестовому массиву в `script.js`. Список доступен для просмотра и изменения в браузере, поэтому прототип не обеспечивает серверный контроль доступа. Введённые адреса не передаются и не сохраняются приложением.
